# Грабли платформы 1С 8.5 (проверено практикой)

Каждый пункт: симптом → причина → решение.

## Формы и динсписки

**Кнопка сортировки «не работает» (клик проходит, порядок не меняется).**
Причина: порядок динсписка сохранён как ПОЛЬЗОВАТЕЛЬСКАЯ настройка (`userSettingID` у `dcsset:order` + автосохранение) — платформа накатывает её поверх кода. Решение: убрать привязку порядка к пользовательским настройкам (в DSL form-compile: `"listSettings": { "order": "" }` в settings динсписка) и в коде ставить `ЭлементПорядка.Использование = Истина;`. Диагностика: добавить `ПоказатьОповещениеПользователя` в обработчик — если оповещение есть, а порядок нет, дело в настройках.

**Стандартные команды сортировки таблиц (SortListAsc/SortListDesc) в 8.5.**
«Invalid name of form item command» — не существуют. Делать свои команды формы + `Список.Порядок.Элементы.Очистить()`, `Добавить(Тип("ЭлементПорядкаКомпоновкиДанных"))`, поле `Description`, `ТипУпорядочивания`, `Использование = Истина` (серверная процедура, `&НаСервере`).

**Группы «HorizontalIfPossible» складываются в один столбец.**
В веб-клиенте 8.5 почти всегда разворачиваются вертикально: поля друг под другом, фото растягивается в пустую рамку, панели «лесенкой». Решение: `"alwaysHorizontal"` (`<Group>AlwaysHorizontal</Group>`) для всех групп, которые обязаны стоять в ряд.

**Вертикальных закладок слева нет.**
`PagesRepresentation` принимает только `None/TabsOnTop/TabsOnBottom`; значения `TabsOnLeft/TabsLeft/VerticalTabs` XDTO отклоняет («Different property and XDTO data item»). Решение: слева группа кнопок с `"type": "hyperlink"`, справа `pages` c `pagesRepresentation: "None"`, переключение `Элементы.Страницы.ТекущаяСтраница = Элементы.СтраницаХ;` в обработчиках команд, стартовая страница — в `ПриСозданииНаСервере`.

**Кнопки команды молча не работают.**
`<Action>` команды должно совпадать с именем процедуры модуля ДО СИМВОЛА. Проверяй `grep -n '<Action>' Form.xml` против `Процедура ... (Команда)` в Module.bsl.

## Регистры и проведение

**«Запись с такими ключевыми полями существует» при проведении разных документов.**
Непериодический регистр сведений имеет ГЛОБАЛЬНО уникальный ключ по измерениям — движения разных документов конфликтуют. Решение: периодичность `Second` у регистра + в каждой `ОбработкаПроведения` явно `Запись.Период = Дата`.

**«Период не может быть пустым».**
Появляется после перевода регистра в периодический, если движения пишутся без периода — та же правка: `Запись.Период = Дата` перед `Записать()`.

**Форма подбора не переносит строки в документ.**
`ОбработкаВыбора` — клиентское событие (`&НаКлиенте`), из формы подбора `ОповеститьОВыборе(Массив)` + `Закрыть()`. Серверный вариант молча не подключается.

**Печать макета: «Непредвиденная ошибка».**
`Новый Шрифт(Ячейка.Шрифт, ...)` на пустом шрифте ячейки падает. Не манипулировать шрифтом отсутствующих элементов макета.

## XML / применение конфигурации

**«Document is empty» при import.** Двойной BOM в файле. Писать ровно один `'\ufeff'` с `encoding='utf-8'`.

**«Different property and XDTO data item: Property Picture».** Картинка у кнопки/команды в DSL — убрать `"picture"`.

**form-compile регистрирует `<Form>` внутрь табличной части.** После компиляции проверять уровень вложенности `<Form>` в объекте (должен быть `\t\t\t`, рядом с прочими формами, не внутри `TabularSection`).

**База «занята», хотя всё закрыто.** Файловая база держится Конфигуратором в монопольном режиме — ibsrv тогда отдаёт статику (200) и виснет на первой сессии. Диагностика: `lsof -nP -iTCP:8314 -sTCP:LISTEN` пуст при живом процессе. Лечение: закрыть Конфигуратор, пересоздать data-каталог ibsrv, поднять заново.
