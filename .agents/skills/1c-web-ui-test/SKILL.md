# Визуальное тестирование 1С в веб-клиенте

Автономный сервер `ibsrv` публикует файловую базу на `http://localhost:8314/labs/ru_RU/`. Управление браузером — через mcp__node_repl__js (скилл browser-use:control-browser), клики по интерфейсу 1С — в основном через `tab.dom_cua`.

## Подъём и остановка сервера

```bash
bash .agents/skills/1c-web-ui-test/scripts/web-up.sh     # поднять и дождаться HTTP 200
bash .agents/skills/1c-web-ui-test/scripts/web-down.sh   # остановить, освободить базу
```

Критично: **база не должна быть занята Конфигуратором пользователя** (монопольный захват). Симптом: curl даёт 200 (статика), а браузер показывает «Не удается установить соединение», и lsof перестаёт видеть LISTEN — сервер повис на открытии базы. Лечение: закрыть Конфигуратор, `web-down.sh`, снова `web-up.sh`. После жёсткого убийства ibsrv каталог `--data` надо пересоздавать чистым (скрипт делает сам).

## Навигация

- Стартовый URL: `http://localhost:8314/labs/ru_RU/` (именно ru_RU, не en_US).
- Список объекта: `#e1cib/list/Справочник.Имя` / `#e1cib/list/Документ.Имя` — работает только как `goto(url)` + `reload()` + `waitForTimeout(4000-5000)`. Прямой `#e1cib/form/...` НЕ работает — формы объектов открывать кликом из списка.
- Если вкладка застряла на «Не удается установить соединение» — не реанимировать, закрыть и открыть новую.

## Клики по интерфейсу 1С (главное)

Локаторы Playwright по тексту в 1С-клиенте часто таймаутятся (элементы без ролей). Рабочий путь:

```js
const dom = await tab.dom_cua.get_visible_dom();
// найти узел по name, собрать ref, затем:
await tab.dom_cua.click({ node_id: ref });
```

- Писать функцию-обходчик DOM-объекта, ищущую `(o.name||'')` по подстроке и собирающую `{ref, rect}`. Брать узел с конкретной геометрией (`rect.width < 300`), а не контейнер во всю ширину.
- Строки таблиц списков: координаты листового узла через `tab.playwright.evaluate` (фильтр `e.children.length===0 && e.textContent.trim()==='...'` → getBoundingClientRect) + `tab.cua.double_click({x,y})`. Координаты могут быть смещены на ~30px — если попал не туда (подсветилась соседняя строка/открылось не то), переснимай геометрию и целься заново, а не повторяй тот же клик.
- Кнопки, спрятанные в «Ещё»: сначала клик по «Ещё» (нижнее — у таблицы), wait 2-3с, потом кнопка появляется в DOM.
- В подписях 1С встречается NBSP (`\u00a0`, «Провести и закрыть») — сравнивать через `includes`, не через ===.
- После клика состояние читать `domSnapshot()`; для визуальной оценки (раскладка) — `screenshot` + `nodeRepl.emitImage`.

## Обязательный завершающий шаг: закрыть процессы и освободить базу

После ЛЮБОЙ проверки — успешной, неудачной или прерванной — остановить веб-сервер:

```bash
bash .agents/skills/1c-web-ui-test/scripts/web-down.sh
```

Это обязательный шаг, а не гигиена «по желанию»: пользователь работает с базой в Конфигураторе, оставленный ibsrv её блокирует и мешает применению конфигурации (пользователь в этом проекте регулярно требует «отрубись от бд»). Убедись, что скрипт отработал (порт 8314 закрыт, процессов ibsrv нет), и в финальном ответе подтверди: сервер остановлен, база свободна. Оставить сервер работать можно ТОЛЬКО по явной просьбе пользователя — и тогда назвать ему команду остановки.

Несённый случайным кликом мусор (открытая форма создания) закрывать Escape/«Закрыть» без записи.
