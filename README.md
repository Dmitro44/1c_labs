# 1С:Предприятие 8.5 — лабораторные работы (БГУИР, «Кадровый учет и финансовое планирование»)

Учебная конфигурация **КадровыйУчетБГУИР** и файловая информационная база `Labs_1s`.
Проект ведётся XML-исходниками (`src/cf`), применяется к базе через `ibcmd`.

## Состав

| Путь | Что это |
|---|---|
| `src/cf/` | XML-исходники конфигурации (справочники, документы, регистры, перечисления, формы, подсистемы) |
| `Labs_1s/` | Файловая информационная база (1Cv8.1CD) — с данными и применённой конфигурацией |
| `build/` | JSON-DSL форм (`lab2_forms/*.json` и др.) и скрипты сборки |
| `lab2_gemini.md`, `Labs_1s/labs_1s.md` | ТЗ лабораторных 1 и 2 |
| `.agents/skills/` | Навыки ZCode: применение конфигурации, сборка форм, веб-тестирование, грабли 8.5 |
| `AGENTS.md` | Правила проекта (обязательное освобождение базы после работы) |
| `Лабы 1С — *.command` | Ярлыки запуска Конфигуратора/Предприятия на macOS |

## Реализовано

**Лаба 1** — справочники (Сотрудники с ~100 реквизитами, СтраныМира с формой классификатора ОКСМ,
Подразделения, Должности, Надбавки и др.), перечисления, 5 форм справочника Сотрудники
(элемента, списка, выбора, расчёта стажа). Форма элемента — с левой панелью разделов
(Личные данные / Адрес / Образование / Стаж / Характеристики-мед. справка / Работа / Дети).

**Лаба 2** — 11 перечислений, 4 документа (Ввод штатной единицы с загрузкой из Excel,
Удаление штатной единицы с формой подбора, Больничные с печатью, Прием на работу с 5 формами),
9 регистров сведений + 1 регистр накопления, подсистемы КадровыйУчет/ПЭУ.

## Как открыть

Платформа 1С 8.5.1.1522+ (macOS: `/opt/1cv8/...`). База файловая:

```bash
/opt/1cv8/8.5.1.1522/1cv8 DESIGNER  /F <путь>/Labs_1s /L ru   # Конфигуратор
/opt/1cv8/8.5.1.1522/1cv8 ENTERPRISE /F <путь>/Labs_1s /L ru   # Предприятие
```

Windows: то же с путём `C:\Program Files\1cv8\<версия>\bin\1cv8.exe`, базу добавить как существующую.

## Инструментарий (не в репозитории)

Сборка форм использует [cc-1c-skills] — клонировать рядом:

```bash
git clone <репозиторий cc-1c-skills> cc-1c-skills
```

Применение конфигурации и веб-проверка — скриптами из `.agents/skills/`:

```bash
bash .agents/skills/1c-config-sync/scripts/apply-config.sh      # src/cf -> база (ibcmd) + CheckConfig
bash .agents/skills/1c-web-ui-test/scripts/web-up.sh            # веб-клиент на http://localhost:8314/labs/ru_RU/
bash .agents/skills/1c-web-ui-test/scripts/web-down.sh          # остановить, освободить базу
```

[cc-1c-skills]: https://github.com/ — инструментарий 1C-скиллов (локальная копия)
