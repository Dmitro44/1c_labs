## Страница 1 (lab3-1.jpg)

# Разработка регистра накопления «РегистрУчетаСотрудников»

## 1. Контекст задачи

Необходимо реализовать хранилище, в котором хранится информация о работающих и уволенных сотрудниках, включая информацию об их должностях и историю работ. Отсутствие данной функциональности не позволит системе предоставлять сведения о текущем и прошлом состоянии кадрового состава предприятия.

## 2. Критерии результата

1. Реализованный регистр обеспечивает хранение информации о сотрудниках и их должностях.
2. Записи регистра содержат историю изменений по каждому сотруднику.
3. Регистр обеспечивает автоматическую запись при проведении связанных документов.
4. Реализована форма списка регистра с отображением всех необходимых данных.

## 3. Порядок выполнения

### 3.1. Создание регистра

- Создать объект «Регистр накопления» с именем **«РегистрУчетаСотрудников»**.
- Вид регистра — **«Остатки»**.
- Режим записи — **«Подчинение регистратору»**.
- Включить регистр в подсистему **«РегистрыПЭУ»**.
- Создать измерения и ресурсы (данные регистра).

**Измерения:**

| Измерение | Тип | Назначение |
|---|---|---|
| Сотрудники | СправочникСсылка.Сотрудники | Конкретный сотрудник |
| Подразделения | СправочникСсылка.Подразделения | Подразделение, в котором работает сотрудник |
| Должности | СправочникСсылка.Должности | Должность сотрудника |
| ВидФинансирования | СправочникСсылка.ВидФинансирования | Вид финансирования конкретного сотрудника |
| ВидыРаботы | ПеречислениеСсылка.ВидРаботы | Вид работы сотрудника |
| ДокументИзменения | ДокументСсылка | Ссылка на документ, который изменил значение записи |

**Ресурсы:**

| Ресурс | Тип | Назначение |
|---|---|---|
| Ставка | Число | Количество свободных ставок по конкретной должности |

### 3.2. Подключение регистраторов

Необходимо реализовать функциональность автоматической записи в разработанный регистр при проведении документов. Документы-регистраторы:

- **ПриемНаРаботу** — документ, при проведении которого добавляются записи о сотрудниках в регистр.

### 3.3. Создание формы списка

Необходимо реализовать интерфейс формы вывода списка записей разработанного регистра с возможностью поиска. В форме списка должны быть отображены следующие поля (список продолжается на следующей странице):

| Поле | Тип | Назначение |
|---|---|---|
| Период | Дата | Дата и время создания записи |
| Регистратор | ДокументСсылка | Документ, добавивший запись в регистр |
| ВидФинансирования | СправочникСсылка.ВидФинансирования | Вид финансирования |
| Сотрудники | СправочникСсылка.Сотрудники | Сотрудник |

*(страница 1 заканчивается пунктом «Сотрудники»; макета интерфейса на странице нет)*

# Разработка регистра накопления «РегистрРаботыСоШтатнымРасписанием»

## 1. Контекст задачи

На данный момент система не имеет возможности отслеживания количества ставок в разрезе подразделений, должностей и видов финансирования. Отсутствие такой функциональности усложняет предоставление руководству оперативной информации о кадровом состоянии подразделений.

## 2. Критерии результата

1. Реализованный регистр обеспечивает хранение информации о свободных ставках по должностям.
2. Записи регистра содержат историю изменения количества ставок по подразделениям.
3. Регистр обеспечивает автоматическую запись при проведении связанных документов.
4. Реализована форма списка регистра с отображением всех необходимых данных.

## 3. Порядок выполнения

### 3.1. Создание регистра

- Создать объект «Регистр накопления» с именем **«РегистрРаботыСоШтатнымРасписанием»**.
- Вид регистра — **«Остатки»**.
- Режим записи — **«Подчинение регистратору»**.
- Включить регистр в подсистему **«РегистрыПЭУ»**.
- Создать измерения и ресурсы.

**Измерения:**

| Измерение | Тип | Назначение |
|---|---|---|
| Подразделения | СправочникСсылка.Подразделения | Подразделение, за которым закреплено штатное расписание |
| Должности | СправочникСсылка.Должности | Должность в рамках подразделения |
| ВидФинансирования | СправочникСсылка.ВидФинансирования | Вид финансирования должности |

**Ресурсы:**

| Ресурс | Тип | Назначение |
|---|---|---|
| Ставка | Число | Количество ставок в разрезе подразделения, должности и вида финансирования |

### 3.2. Регистраторы

Необходимо реализовать функциональность автоматической записи в разработанный регистр при проведении документов. Документы-регистраторы:

- **ВводШтатнойЕдиницы** — при проведении добавляет записи о новых ставках;
- **УдалениеШтатнойЕдиницы** — при проведении изменяет количество ставок по подразделению.

### 3.3. Форма списка

Необходимо реализовать интерфейс формы вывода списка записей разработанного регистра с возможностью поиска. В форме списка должны быть отображены следующие поля (список продолжается на следующей странице):

| Поле | Тип | Назначение |
|---|---|---|
| Период | Дата | Дата создания записи |
| Регистратор | ДокументСсылка | Документ, проведение которого добавило запись |
| Подразделение | СправочникСсылка.Подразделения | Подразделение |
| Должности | СправочникСсылка.Должности | Должность |
| Вид финансирования | СправочникСсылка.ВидФинансирования | Вид финансирования |

*(низ страницы частично перекрыт текстом следующей страницы (просвечивает); макета интерфейса на странице нет)*

## 3.4. Интерфейс разрабатываемого регистра

Примерный вид формы списка для разрабатываемого регистра:

**[МАКЕТ ИНТЕРФЕЙСА — скриншот формы списка]:**

- **Заголовок окна:** «Регистр работы со штатным расписанием».
- **Панель инструментов (над таблицей, слева направо):** кнопки «Добавить», «Копировать», «Изменить», «Удалить», «Найти», «Настройка списка», «Вывести список», «Обновить» (стандартная командная панель формы списка; часть кнопок может быть скрыта/объединена в меню).
- **Строка поиска/фильтрации:** поле быстрого поиска над таблицей.
- **Таблица записей — колонки слева направо:**
  1. **Период** (дата и время; в видимых строках — 01.09.2025 10:00);
  2. **Регистратор** (гиперссылка на документ; в видимых строках — «Ввод штатной единицы №… от 01.09.2025 10:00»);
  3. **Подразделение** (в видимых строках — «Кафедра информатики», «Кафедра защиты информации»);
  4. **Должности** (в видимых строках — «Старший преподаватель», «Доцент»);
  5. **ВидФинансирования** (в видимых строках — «Бюджет», «Внебюджет»);
  6. **Ставка** (число; в видимых строках — 4,5; 1).
- **Строки данных:** табличная часть заполнена примерами записей (2–3 видимые строки, где чередуются подразделения/должности/значения ставок).
- **Внизу окна:** информационная строка количества записей (например, «Количество: N»), поле и режим просмотра (стандартная панель состояния списка 1С).
