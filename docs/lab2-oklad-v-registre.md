# Как добавить оклад в регистр «РегистрРаботыСоШтатнымРасписанием»

> Необязательная доработка. Сейчас оклад **не хранится** в регистре (по ТЗ лабы 3 там только ресурс
> `Ставка`), поэтому форма подбора берёт оклад и разряд из проведённых документов «Ввод штатной единицы».
> Инструкция — на случай, если понадобится хранить оклад в регистре «по-настоящему»:
> тогда `Ввод` пишет приход оклада, `Удаление` — расход, а подбор показывает остаток оклада.

## 0. Сначала бэкап

Закрой 1С, скопируй папку `TOFD\Labs_1s` (или Конфигуратор → **Администрирование → Выгрузить информационную базу**).

## 1. Добавить ресурс `Оклад` в регистр

1. Открой **Конфигуратор**.
2. В дереве: **Регистры накопления → РегистрРаботыСоШтатнымРасписанием** → двойной клик.
3. Вкладка **«Данные»** → в списке **Ресурсы** нажми **Добавить** (`Ins`).
4. Заполни:
   - **Имя:** `Оклад`
   - **Синоним:** `Оклад`
   - **Тип:** `Число`, **Длина:** `15`, **Точность:** `2`
5. Измерения (`Подразделения`, `Должности`, `ВидФинансирования`) **не трогай**.

## 2. Писать оклад при вводе

1. **Документы → ВводШтатнойЕдиницы** → правая кнопка → **Открыть модуль объекта**.
2. В процедуре `ОбработкаПроведения` найди строку:
   ```bsl
   Запись.Ставка           = СтрокаШтатнойЕдиницы.Ставка;
   ```
   и добавь под неё:
   ```bsl
   Запись.Оклад            = СтрокаШтатнойЕдиницы.Оклад;
   ```

## 3. Писать оклад при удалении

1. **Документы → УдалениеШтатнойЕдиницы** → правая кнопка → **Открыть модуль объекта**.
2. В `ОбработкаПроведения` найди:
   ```bsl
   Запись.Ставка           = СтрокаШтатнойЕдиницы.Ставка;
   ```
   и добавь:
   ```bsl
   Запись.Оклад            = СтрокаШтатнойЕдиницы.Оклад;
   ```

## 4. Поменять запрос формы подбора

1. В дереве: **Документы → УдалениеШтатнойЕдиницы → Формы → ФормаПодбора** → правая кнопка → **Открыть модуль**
   (или двойной клик по форме → вкладка «Модуль»).
2. В процедуре `ЗаполнитьСписокШтатныхЕдиниц` замени весь текст запроса на такой:

```bsl
	ТекстЗапроса =
	"ВЫБРАТЬ
	|	Остатки.Подразделения КАК Подразделение,
	|	Остатки.Должности КАК Должность,
	|	Остатки.ВидФинансирования КАК Финансирование,
	|	Остатки.СтавкаОстаток КАК Ставка,
	|	Остатки.ОкладОстаток КАК Оклад
	|ИЗ
	|	РегистрНакопления.РегистрРаботыСоШтатнымРасписанием.Остатки(&ДатаОстатков, ) КАК Остатки
	|ГДЕ
	|	Остатки.СтавкаОстаток > 0";
```

Остальную часть процедуры (отборы, `УПОРЯДОЧИТЬ ПО`, заполнение строк таблицы) менять не нужно.

Разряд в регистре так и остаётся брать неоткуда — если он тоже нужен «по-настоящему»,
добавь его отдельным **измерением** (`Разряд`, тип Число, длина 2, точность 0) и заполняй в обоих документах
строкой `Запись.Разряд = СтрокаШтатнойЕдиницы.Разряд;`. Тогда в запросе вместо соединения пиши
`Остатки.Разряд КАК Разряд`.

## 5. Применить изменения

**Конфигурация → Обновить конфигурацию базы данных** (`F7`).

## 6. Перепровести документы

У уже существующих движений оклад будет `0` (ресурс появился позже). Открой каждый документ
«Ввод штатной единицы» и нажми **«Провести»** (либо **Все функции → Обработки → Групповое проведение документов**,
если доступно). То же для «Удаление штатной единицы».

## 7. Проверка

1. Проведи «Ввод штатной единицы» (например, ЦПОУ / Ректор / Бюджет / 12 разряд / 1 ставка / 1260 оклад).
2. Создай «Удаление штатной единицы» → **Подобрать**: в строке должен быть оклад `1260`.
3. Отметь, **Выбрать**, затем **Провести**.
4. Открой подбор снова — эта строка должна исчезнуть (остаток ставки и оклада стал 0).

Проверить движения напрямую: **Регистры накопления → РегистрРаботыСоШтатнымРасписанием** — в записях появится колонка `Оклад`
(приход у ввода, расход у удаления).

## Как откатить

1. Удалить ресурс `Оклад` из регистра (вкладка «Данные»).
2. Убрать добавленные строки `Запись.Оклад = ...` в обоих модулях объектов.
3. Вернуть прежний текст запроса в `ЗаполнитьСписокШтатныхЕдиниц` (с `ЛЕВОЕ СОЕДИНЕНИЕ` к документу ввода) —
   исходный вариант есть в истории файла `src/cf/Documents/УдалениеШтатнойЕдиницы/Forms/ФормаПодбора/Ext/Form/Module.bsl`.
4. `F7`, перепровести документы.
